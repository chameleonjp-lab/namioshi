## 実施する流れ

1. 初回アクセス、HOME表示、名前入力
2. RULES開閉、キーボードを閉じてCOUNTDOWNへ進む
3. 3、2、1、STARTを確認する
4. 6回入力し、7回目が無視されることを確認する
5. 直接、壁反射、反射板、2回反射の見分けを確認する
6. RESULT、再挑戦、モード選択、シェアを確認する
7. オフライン時の送信失敗表示と、オンライン復帰後の導線を確認する
8. 画面回転、バックグラウンド復帰、音、振動、reduced-motionを確認する
