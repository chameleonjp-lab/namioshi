この文書は、Phase 3Cの候補C実装を再確認し、今回補修する問題と後続Phaseへ残す問題を分けて記録する。

## 1. 確認できたこと

- 候補Cの座標、速度、配置ID、指紋、ルール版は比較元と一致する。
- 公式配置と練習ランダムの生成処理は分かれている。
- 公式初期化は固定乱数を使い、練習は別の乱数を使う。
- 現行`src/main.js`はランキング送信関数を呼ばない。
- Phase 3Cマージ時点の`src`と`dist/assets`は一致する。

## 2. Phase 3C follow-upで補修すること

### RESULTからモードを変えられない

Phase 3Cマージ時点のRESULTには「同じモードでもう一度」しかなく、再読み込みなしでは公式から練習、練習から公式へ移れなかった。

RESULTへモード選択へ戻る導線を追加する。

### 前回盤面が次の開始前に見える

Worldの再初期化はカウントダウン終了後に行うため、半透明のHOMEやCOUNTDOWNから前回の盤面が見えた。練習では、次のランダム配置とは異なる前回配置を開始前に見せることになる。

HOME、RULES、COUNTDOWNを不透明にし、前回盤面を開始前の情報として見せない。

### 送信停止が呼び出し側だけに依存する

停止状態が`enabled=false`でも、`submitScore()`を直接呼ぶと通信を開始できた。

Phase 5までは、送信関数の入口でも停止状態を確認し、`fetch()`より前に拒否する。

### 不明なモードが公式扱いになる

公式と練習以外の値が公式へ読み替えられていた。誤った値をランキング候補へ昇格させないよう、不明なモードを拒否する。

## 3. 後続Phaseへ残す重要問題

### Phase 4C: 画面更新間隔で得点が変わる

現行の可変時間更新では、同じ候補C、同じ3タップ、同じ5秒でも得点が一致しない。

```text
60分割: 24,525点
120分割: 24,012点
```

命中を各更新時点で採点するため、更新間隔によって命中誤差が変わる。Phase 4Cの固定更新と、60Hz相当・120Hz相当の比較試験で解消する。正式ランキングを再開する前の必須条件とする。

### Phase 4A: 同じ面を再判定できる距離が未定義

正本文書の「十分な移動距離を消費するまで同じ面で再反射させない」には、距離の数値または計算規則がない。Phase 4A開始前に契約を決め、決定ログへ記録する。

### Phase 5: 停止中の旧ランキング契約

停止中の通信関数には、旧`CLIENT_VERSION`と`Authorization: Bearer`が残る。この補修ブランチでは送信関数の入口で拒否するため通信しない。

Phase 5では、正式な接続先、`apikey`だけを使う契約、v3の版、旧記録との分離をまとめて確認する。停止解除だけを先に行わない。

### Phase 7: 画質によって見えない波が判定される

Worldは最大24波を判定するが、WebGLは画質により先頭7、10、12波だけを描く。Canvas 2Dは全波を描く。

判定される波を画質だけで非表示にしない。画質低下は粒子、解像度、残像などへ寄せ、少なくとも簡略表示で全判定波を見せる。

### Phase 7D: WebGL途中失敗後のCanvas切り替え

同じcanvasでWebGL contextを取得した後に初期化が失敗すると、同じcanvasから2D contextを取得できず、Canvasフォールバックも失敗する場合がある。

Phase 7Dでcanvasの置換または別canvasによる安全な切り替えを実装する。

### Phase 6: 共有と小画面

- 練習結果の共有文が公式結果と区別できない。
- HOME共有が0点の結果文になる。
- 画面全体のsafe-area対応は未完了である。

共有文、RESULT導線、safe-areaはPhase 6でまとめて修正する。

### 練習配置

練習用ガラス片は終点を論理画面内へ制限していないため、一部が画面外へ出る可能性がある。候補Cの公式配置には影響しない。練習配置の変更は、従来ランダム規則を維持するPhase 3Cとは分けて判断する。

## 4. G3の残り

G3の「同じ入力で同じ結果」は、同じタップと同じ物理step列での再現性を指し、自動試験で確認済みである。60Hz相当と120Hz相当のように物理step列が異なる場合の一致は、Phase 4Cの固定更新とG4で解消する。

自動試験だけではG3を完全通過にしない。次をiPhoneで確認する。

- 候補Cの端側ガラスを識別できる。
- HOMEの公式・練習カードを操作できる。
- 公式から練習、練習から公式へ切り替えられる。
- 再挑戦とモード再選択で前回盤面を次の配置と誤認しない。

端側ガラスが見づらい場合は、Phase 4Aへ進まず候補Dの比較へ戻る。
